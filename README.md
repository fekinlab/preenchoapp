# preenchoapp
Protótipo do app Preenchô

## Homologação no Mac · por duplo clique

[Baixe o ZIP de homologação](https://github.com/fekinlab/preenchoapp/archive/refs/heads/dev/extensao-consentimento.zip), descompacte em Downloads e abra **Iniciar no Mac.command**. O iniciador prepara um perfil de teste no Chrome, configura duas origens locais, destaca a pasta da extensão e abre um guia com os botões para o cofre e o cadastro. Se o macOS oferecer as ferramentas de desenvolvedor, conclua a instalação e abra o iniciador novamente. Para Safari, use **Preparar Safari.command** em um Mac com Xcode. [Guia do Mac e do iPhone](extension/README.md).
